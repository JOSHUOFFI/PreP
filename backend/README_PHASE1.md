# PrePa Phase 1 Notes

This file is a placeholder for Phase 1 implementation notes while upgrading PrePa from the current minimal backend into a production-ready Node/Express + MongoDB/Mongoose architecture.

## Phase 1 targets
- Node/Express backend entry + routing structure
- MongoDB connection using Mongoose
- Mongoose models: User (required fields)
- Auth: bcrypt password hashing + JWT issuance
- Protected routes middleware
- Keep compatibility with existing `POST /api/classroom` endpoint and frontend contract.
